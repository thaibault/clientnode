Methods

acquire(description, callback, autoRelease)

Calling this method introduces a starting point for a critical area with potential race conditions. The area will be bind to given description string. So don't use same names for different areas.
Parameters:
Name Type Default Description
description A short string describing the critical areas properties.
callback A procedure which should only be executed if the interpreter isn't in the given critical area. The lock description string will be given to the callback function.
autoRelease false Release the lock after execution of given callback.
Source:

Returns:
Returns a promise which will be resolved after releasing lock.
